# 桌面操作标注说明（__PACK__）

## 这是在做什么

我们在训练一个小模型，让它在 Mac 上替人操作 Finder（访达）和 TextEdit（文本编辑），比如"把所有 .log 文件移进新建的 reports 文件夹"。模型每一步都要回答几道选择题：先选**做哪种操作**，再选**对谁做**、**写什么**。

这批题目是模型实际跑任务时走到的画面，其中很多是它**已经走错了一步**之后的样子：改错了文件名、进错了文件夹、把值写错了。你要做的是：**站在这个画面上，从给出的选项里选出最合适的下一步**。

一共 __N__ 题。每题大约 1～2 分钟。

## 怎么做

1. 双击打开 `annotate.html`（用 Chrome、Edge 或 Safari 都可以，不需要联网）。
2. 在顶部填上一个称呼（名字或昵称都可以），用来区分不同标注员的答案。
3. 每一题：
   - 左边看情况：**任务目标**、**任务最终要达到的结果**、**已经做成的事**、**最近几步**、**屏幕上的元素**。
   - 右边答题：先选"做哪种操作"，下面会出现这个操作需要的问题（比如改名要选"给哪个文件改名"和"新名字"），全部选完这题才算完成。
4. 进度会自动保存在浏览器里，关掉再打开也不会丢（请用同一个浏览器）。
5. 全部做完后，点右上角 **导出答案**，把下载的 `answers_….json` 文件发回给我们。

## 判断原则

- **目标是"最终要达到的结果"那一栏**。用户的原话可能有歧义，以那一栏为准。
- **选能让离最终结果更近一步的操作**，一次只选一步，不用考虑后面几步。
- **先纠错，再继续**：如果之前做错了（比如把 page2.txt 错改成了 page1-old.txt），下一步应该是把错的改回来或改成正确的名字，而不是装作没看见。
- **不要动与任务无关的文件**，尤其是 `keep` 文件夹和 `reference.txt`，它们是用来检查"有没有乱动"的。
- **写入的内容必须和最终结果里的文字完全一致**，不要写说明性的话或例子（例如目标里"形如 P-1047"只是示例）。
- **修改文档用"替换一段文字"**：只换掉需要改的那一段，不要用"输入 / 覆盖文字"把整篇重写。
- **写完要保存**：文档内容对了但还没保存，下一步就是点"保存"或按 ⌘S。
- **全部做完就选"任务已完成"**，不要再做多余的操作。
- **不确定的时候**：如果选项里确实没有能推进任务的操作（比如需要的窗口已经被关掉、选项里也没有打开它的办法），勾选"无法判断"，并在备注里写一句原因。不要随便选。

## 常见操作的含义

| 操作 | 含义 | 还要回答 |
|---|---|---|
| 点击 | 点一个按钮或链接。在 Finder 里点文件夹（蓝色链接）就是进入它；点文件只会选中，没有其他效果 | 点哪个元素 |
| 打开（双击） | 打开文件夹或文件 | 打开哪个 |
| 在下拉框里选择 | 用"移动「某文件」到"下拉框把文件移到某个文件夹 | 选哪一项 |
| 改名 | 给文件或文件夹改名 | 给谁改、新名字 |
| 替换文档里的一段文字 | 在文档里把一段原文换成新内容 | 哪个文档、换哪段、换成什么 |
| 输入 / 覆盖文字 | 往空的输入框或空文档里写内容；会覆盖原有内容 | 往哪里、写什么 |
| 切换窗口 | 切到另一个已经打开的文档或文件夹窗口 | 切到哪个 |
| 按快捷键 | 例如 ⌘S 保存、⌘↑ 回到上一级文件夹 | 哪个快捷键 |
| 任务已完成 | 最终结果已经全部达到 | — |
| 无法继续 | 尽量不要选，用"无法判断"代替 | — |

## 质量要求

- 题目里混有一部分**已知正确答案的检查题**，用来评估标注质量，你看不出哪些是。
- 请独立完成，不要和别人对答案。
- 每题都认真看"最终要达到的结果"和"已经做成的事"，这两栏最关键。

## 隐私说明

题目里的文件和文字都是测试用的虚构内容，不涉及真实用户数据。请不要把题目内容转发给无关人员。
